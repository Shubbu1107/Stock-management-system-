## Project title: *Stock Control System*

## Student name: *Shubham Hariyale*

### Student email: *sh1035@student.le.ac.uk*

## 1. Project Description

This project focuses on the design and implementation of a secure web-based stock control management system intended for small to medium-scale organisational environments.

The system goes beyond basic CRUD functionality by investigating secure role-based access control (RBAC), transactional integrity, and data consistency under concurrent access.

The project aims to analyse how hierarchical access control and database transaction mechanisms can be integrated to ensure reliable and secure stock operations in a multi-user web environment. The system is implemented using ASP.NET Web Forms and SQL Server while applying layered architectural principles to improve maintainability.



## 2. Requirements and Objectives

### High Level Objectives

- Design a secure role-based access control model.
- Ensure transactional integrity in stock updates.
- Maintain data consistency under concurrent access.
- Apply layered architecture principles.
- Evaluate system performance and framework limitations.



### Essential Requirements

- Secure authentication using session-based validation
- Hierarchical role-based access control (SuperAdmin, Admin, Staff, Auditor)
- Inventory item management (Admin restricted)
- Stock movement recording (IN/OUT)
- SQL transaction handling for atomic updates
- Validation to prevent negative stock values
- Parameterised queries to prevent SQL injection
- Backend role validation to prevent unauthorised URL access



### Desirable Requirements

- Audit logging of critical operations
- Role-permission mapping structure
- Concurrency simulation testing
- Database indexing for performance optimisation.
- Isolation behaviour analysis



### Optional Requirements

- Reporting dashboard
- Extended performance benchmarking
- Scalability discussion for larger datasets
- Additional role hierarchy expansion



## 3. Project Nature

This project is primarily a software development and system design project with an analytical and evaluative component.

It combines practical implementation with investigation of:

- Secure role-based access control models
- Database transaction theory (ACID properties)
- Concurrency handling in multi-user systems
- Architectural trade-offs within ASP.NET Web Forms

The project therefore includes both engineering development and structured evaluation.



## 4. Technologies Used

- ASP.NET Web Forms (.NET Framework 4.8)
- C#
- SQL Server
- Layered architecture design
